# MediaScout-feedback

## How to raise a bug report or feature request

You don't need any GitHub experience to use this — here's the whole process:

1. **Sign in (or create a free account).** Go to [github.com](https://github.com/) and click "Sign up" in the top right if you don't already have an account. It's free and only takes a minute (email + password).
2. **Open the "New issue" page.** Go to the [Issues tab](https://github.com/th3snark/MediaScout-feedback/issues), then click the green **New issue** button.
3. **Pick a template.** You'll see two options:
   - **Bug Report** — something in MediaScout isn't working correctly.
   - **Feature Request** — an idea or improvement you'd like to see.

   Click **Get started** next to whichever one fits.
4. **Fill in the form.** Each field has a short description of what to write. For a bug report, the more detail you can give on what you did and what went wrong, the easier it is to fix. You can find your MediaScout version in the app under **Help > About**.
5. **Click "Submit new issue"** at the bottom of the page. That's it — your report is now visible and I'll follow up on it directly on that page.

You can come back to the same [Issues page](https://github.com/th3snark/MediaScout-feedback/issues) at any time to check on the status of something you've reported, or add more details by scrolling to the bottom of your issue and typing in the comment box.

## What is this repo?

This is where you can report bugs or suggest features for **MediaScout**, a Windows app that scans your Movies and TV Shows folders, looks up metadata (titles, artwork, cast, genres, etc.) from TheMovieDB and TheTVDB, and writes it back out as sidecar files your media center (Kodi, Plex, Emby, Jellyfin, My Movies) can use.

MediaScout's own source code lives in a separate, private repository — this repo exists solely as a public place to leave feedback.

Website (downloads, release notes, how it works): **[mediascout.e2e4.co.uk](https://mediascout.e2e4.co.uk/)**
